# ARDUINO

🇮🇹 Italiano | [🇬🇧 English](README.en.md)

Questa cartella raccoglie i **progetti Arduino** sviluppati e utilizzati durante le lezioni e le attività di laboratorio.

I materiali hanno finalità didattiche e sono pensati per applicare in modo pratico concetti di **elettronica, programmazione, acquisizione dati, sensoristica, automazione e controllo**.

All'interno delle varie sottocartelle possono essere presenti:

- sketch Arduino (`.ino`);
- schemi di collegamento;
- esempi con sensori e attuatori;
- sistemi di acquisizione e visualizzazione dei dati;
- esercitazioni di laboratorio;
- documentazione e note di supporto;
- eventuali file utilizzati insieme ad altri software, come Python.
