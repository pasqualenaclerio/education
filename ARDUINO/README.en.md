# ARDUINO

[🇮🇹 Italiano](README.md) | 🇬🇧 English

This folder contains **Arduino projects** developed and used during lessons and laboratory activities.

The materials are intended for educational purposes and are designed to apply concepts of **electronics, programming, data acquisition, sensors, automation, and control** through practical activities.

The project folders may include:

- Arduino sketches (`.ino`);
- wiring diagrams;
- examples using sensors and actuators;
- data acquisition and visualization systems;
- laboratory exercises;
- supporting documentation and notes;
- files used together with other software, such as Python.
