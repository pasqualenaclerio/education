Laboratorio filtri RC

Un segnale con componenti indesiderate entra in un filtro fatto solo di resistenze e condensatori. Scegli il filtro, cambia i valori, guarda e ascolta che cosa ne esce.

3Segnale in uscita

Passa da ingresso a uscita mentre ascolti: il suono riprende dallo stesso punto, così il confronto è immediato. Il volume non viene ritoccato, quindi senti anche quanto il filtro attenua.

Assi, finestra di tempo e scala dello spettro sono gli stessi dell'ingresso.

Le formule

Gli esempi usano gli stessi valori degli esempi pronti: puoi controllarli sui grafici qui sopra.

Frequenza di taglio

fc = 12π R C

Separa ciò che passa da ciò che viene attenuato. A fc l'uscita vale 0,707 volte l'ingresso (−3 dB) ed è sfasata di 45°.

R = 12π fc C per progettare

Esempio R = 4,7 kΩ, C = 100 nF → fc ≈ 339 Hz

Passa basso

|H| = 11 + (f / fc)2
φ = −arctan(f / fc)

Sotto fc passa quasi tutto. Sopra, ogni decade di frequenza toglie 20 dB; la fase va da 0° a −90°.

Esempio fc = 339 Hz, f = 1760 Hz → |H| ≈ 0,189 (−14,5 dB), φ ≈ −79°

Passa alto

|H| = f / fc1 + (f / fc)2
φ = 90° − arctan(f / fc)

Il condensatore in serie blocca le frequenze basse. Sotto fc si perdono 20 dB per decade; la fase va da +90° a 0°.

Esempio fc = 339 Hz, f = 50 Hz → |H| ≈ 0,146 (−16,7 dB), φ ≈ +82°

Guadagno in decibel

G = 20 · log10 VoutVin
dB0−3−6−20−40
volte10,7070,50,10,01

Esempio Vin = 2 V, Vout = 0,5 V → G = 20 · log10 0,25 ≈ −12 dB

Celle in cascata

|Htot| = |H|n Gtot = n · G
f−3 dB = fc · 21/n − 1 passa basso

Con n celle separate da buffer la pendenza diventa 20 · n dB per decade, ma il taglio a −3 dB si sposta.

Esempio 3 celle, f = 1760 Hz → 0,1893 ≈ 0,0067 (−43,4 dB); taglio a 173 Hz

Passa banda

fL = 12π R1C1 fH = 12π R2C2
f0 = fL · fH B = fH − fL

Passa la banda tra fL e fH. Senza buffer le due celle si caricano: conviene R2 ≥ 10 · R1.

Esempio fL ≈ 219 Hz, fH ≈ 2,19 kHz → f0 ≈ 693 Hz, B ≈ 1,97 kHz
