# TEEA — 3MAT — Laboratory

[🇮🇹 Italiano](README.md) | 🇬🇧 English

This folder contains the TEEA **laboratory web apps** for the **3rd-year MAT class**.

Each web app goes in its own subfolder with an `index.html` file, for example:

```text
laboratorio/
└── web-app-name/
    └── index.html
```

## Web apps

- [`laboratorio-legge-ohm`](laboratorio-legge-ohm/) — **Ohm's law**: source and resistors, Ohm's law, V–I characteristic, colour code, series and parallel, power and energy
