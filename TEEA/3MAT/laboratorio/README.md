# TEEA — 3MAT — Laboratorio

🇮🇹 Italiano | [🇬🇧 English](README.en.md)

Questa cartella raccoglie le **web app di laboratorio** di TEEA per la **classe 3ª MAT**.

Ogni web app va inserita in una propria sottocartella con un file `index.html`, ad esempio:

```text
laboratorio/
└── nome-web-app/
    └── index.html
```

## Web app

- [`laboratorio-legge-ohm`](laboratorio-legge-ohm/) — **Legge di Ohm**: generatore e resistenze, legge di Ohm, caratteristica V–I, codice colori, serie e parallelo, potenza ed energia
